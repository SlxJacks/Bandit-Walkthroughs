# Bandit Level 3

## Goal

Get the password for user bandit3 from filename --spaces in this filename-- located in the home directory

## Command Used

### To list out files and confirm the file
```bash
ls -l
```

### To check the contents of the file
```bash
cat "./--spaces in this filename--"
```

### I used "" here becuase the file name contains the spaces there is alternative for this as well check the below

```bash
cat -- "--spaces in this filename--"
```
