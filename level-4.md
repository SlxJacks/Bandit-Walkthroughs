# Bandit Level 4

## Goal

Get the password for next level from hidden file in inhere directory

## Command Used

### To list out directory and confirm the directory
```bash
ls -l
```

### To go into the directory
```bash
cd inhere/
```

### To list out all files including the hidden file
```bash
ls -la
```

### By using the below command we have read the content for the file which we will need for the next level

```bash
cat "./...Hiding-From-You"
```

### Last output would be something like this only containing password for the next game
2WmrDFRmJIq3IPxneAaMGhap0pFhF3NJ
